# Florian – das Feuerwehr-Tamagotchi

Ein kleines Tamagotchi mit einem Feuerwehrmann: füttern, trainieren, duschen, Karten spielen – und bei Alarm ausrücken.
Funktioniert als installierbare App auch offline.

**Spielen & installieren:** https://schmelzenbart.github.io/florian-tamagotchi/

**Android-App (ohne Browser):** https://schmelzenbart.github.io/florian-tamagotchi/florian.apk
